# Working agreement

Read README.md, docs/DESIGN.md and docs/ROADMAP.md before extending this project.

The owner requires a public repository and an excellent English README before development, followed by a commit and push for each completed, verified increment. Preserve unrelated changes. Inspect staged content for keys/private data. Never backdate commits or manufacture contribution activity.

RAG and a bounded agent are core deliverables. Do not quietly replace them with a deterministic-only product. Build deterministic evidence/tool safeguards first, keep a fixed RAG comparison, and do not assume agent superiority.

Do not call a live model without explicit configured user credentials and opt-in. Do not log keys or redistribute third-party documents without checking terms. No autonomous policy editing or compliance verdicts.

Keep planned, implemented and measured capabilities distinct. Unit tests establish only their actual coverage. Read-only inspection/diagnosis does not authorize new features or remote writes beyond the user's request. No sub-agent requirement is imposed.
